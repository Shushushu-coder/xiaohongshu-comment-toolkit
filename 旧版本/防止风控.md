# 小红书爬虫防风控完整攻略 🛡️

## 🎯 问题分析

你遇到的"当前页面无法访问，请扫描手机查看"是小红书的**设备指纹+行为分析**风控系统触发的。

### 风控检测的维度

1. **设备指纹** (最重要!)
   - Canvas指纹
   - WebGL指纹
   - 字体列表
   - 浏览器插件
   - 屏幕分辨率

2. **浏览器特征**
   - navigator.webdriver (暴露自动化)
   - chrome.runtime (Selenium标记)
   - 缺失的浏览器API

3. **行为模式**
   - 鼠标轨迹（是否过于规律）
   - 滚动速度（是否恒定）
   - 点击位置（是否精准）
   - 停留时间（是否过短）

4. **访问模式**
   - 直接跳转到搜索页 = 机器人
   - 没有首页浏览记录 = 异常
   - 访问频率过高 = 风险

## 💡 解决方案（按成功率排序）

### 方案1: 手动预热 + 半自动化 ⭐⭐⭐⭐⭐

**成功率**: 95%
**所需时间**: 每天1-2小时
**适合**: 学术研究、小规模爬取

#### 操作步骤

**第一天（账号养成）:**
1. 手动登录小红书
2. 像正常用户一样使用30-60分钟：
   - 刷首页推荐
   - 点赞5-10个笔记
   - 收藏2-3个笔记
   - 关注1-2个人
   - 发表1-2条评论（甚至只是表情）
   - 搜索其他无关内容（如"美食"、"旅游"）
3. **不要搜索目标关键词！**
4. 退出，等待24小时

**第二天（测试）:**
1. 手动登录
2. 随便浏览10分钟
3. 手动搜索"谷雨"
4. 如果能正常看到结果 → 账号已预热成功
5. 如果还是被风控 → 继续养号1-2天

**第三天（开始爬取）:**
1. 运行 `start_improved.bat` 启动Chrome
2. 手动浏览5-10分钟
3. 运行 `python main_improved.py`
4. 只爬取5个笔记
5. 关闭，等待4-6小时
6. 重复上述流程（每天最多3次）

### 方案2: Undetected-ChromeDriver ⭐⭐⭐⭐⭐

**成功率**: 90%
**所需时间**: 配置1小时 + 每天自动运行
**适合**: 中等规模爬取

#### 安装

```bash
pip install undetected-chromedriver
```

#### 使用

```bash
python main_undetected.py
```

#### 原理
- 自动Patch ChromeDriver特征
- 移除 `navigator.webdriver`
- 伪装浏览器指纹
- 几乎无法被检测

#### 注意事项
- 首次使用仍需手动预热账号
- 不能频繁运行（每天最多3次）
- 建议配合代理IP使用

### 方案3: 完全手动 + 浏览器插件辅助 ⭐⭐⭐⭐

**成功率**: 100%
**所需时间**: 高（全手动）
**适合**: 小规模、高质量数据收集

#### 工具推荐

1. **Web Scraper (Chrome插件)**
   - 可视化配置爬取规则
   - 在真实浏览器环境运行
   - 完全不会被检测

2. **Instant Data Scraper**
   - 自动识别列表结构
   - 一键导出数据
   - 简单易用

3. **Copy All URLs**
   - 批量复制笔记链接
   - 后续用脚本处理

#### 操作流程

1. 手动搜索"谷雨"
2. 使用插件提取笔记链接
3. 用脚本批量访问链接（间隔较长）
4. 提取评论数据

### 方案4: 代理IP + 账号矩阵 ⭐⭐⭐

**成功率**: 70-80%
**成本**: 高（需购买代理和手机号）
**适合**: 商业化、大规模爬取

#### 配置

1. **代理IP池**
   - 购买住宅代理（不要用数据中心IP）
   - 每个账号绑定1个固定IP
   - 定期更换

2. **多账号**
   - 准备3-5个小红书账号
   - 每个账号独立养号
   - 轮流使用

3. **运行策略**
   - 每个账号每天只爬5-10个笔记
   - 账号间间隔1小时切换
   - 避开高峰期（晚8-11点）

## 🔧 技术优化建议

### 1. 浏览器指纹伪装

```python
# 在driver初始化后立即执行
driver.execute_cdp_cmd('Page.addScriptToEvaluateOnNewDocument', {
    'source': '''
        // 移除webdriver标记
        Object.defineProperty(navigator, 'webdriver', {
            get: () => undefined
        });
        
        // 伪装chrome对象
        window.chrome = {
            runtime: {},
            loadTimes: function() {},
            csi: function() {},
            app: {}
        };
        
        // 伪装插件
        Object.defineProperty(navigator, 'plugins', {
            get: () => [
                {name: 'Chrome PDF Plugin'},
                {name: 'Chrome PDF Viewer'},
                {name: 'Native Client'}
            ]
        });
        
        // 伪装语言
        Object.defineProperty(navigator, 'languages', {
            get: () => ['zh-CN', 'zh', 'en-US', 'en']
        });
        
        // 伪装平台
        Object.defineProperty(navigator, 'platform', {
            get: () => 'Win32'
        });
    '''
})
```

### 4. Cookie持久化

```python
import pickle

# 保存Cookie
def save_cookies(driver, path):
    with open(path, 'wb') as f:
        pickle.dump(driver.get_cookies(), f)

# 加载Cookie
def load_cookies(driver, path):
    with open(path, 'rb') as f:
        cookies = pickle.load(f)
        for cookie in cookies:
            driver.add_cookie(cookie)
```

## 🚨 紧急处理方案

### 如果已经被风控

1. **立即停止所有爬取活动**
2. **手动使用账号30分钟**（正常浏览）
3. **等待24-48小时**
4. **更换IP**（如果可能）
5. **重新养号**

### 如果账号被封

1. **不要慌张**，小红书很少永久封号
2. **停止使用7天**
3. **期间可以手动浏览**（不要搜索敏感词）
4. **7天后测试能否正常使用**
5. **如果仍被封，准备新账号**
