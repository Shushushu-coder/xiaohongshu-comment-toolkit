## ⚠️ 常见问题

### Q1: 提取的评论数量很少？

**可能原因**：

1. 笔记本身评论就少
2. 需要滚动更多次加载评论
3. 页面结构变化，选择器失效

**解决方法**：

- 增加 `max_scrolls` 参数（默认20，可改为30-50）
- 手动滚动到底部后再运行提取
- 查看日志确认使用了哪个选择器

### Q2: 还是有少量无关内容？

**正常现象**：

- 由于页面结构复杂，可能有1-5%的误提取
- 可以在后续数据处理中进一步过滤
- 建议按 `content_length` 筛选（保留 >10 字符的）

### Q3: 时间字段为空？

**说明**：

- 小红书的评论时间可能是动态加载的
- 不影响评论内容的有效性
- 可以用 `collected_at` 字段记录采集时间

### Q4: 批量处理中断了？

**解决方法**：

1. 查看已保存的文件
2. 删除 `note_urls.txt` 中已完成的URL
3. 重新运行程序继续剩余部分

## 💡 优化原理

### 核心改进

#### 1. 多层过滤机制

```python
# 第一层：选择器精准定位
comment_elements = driver.find_elements(By.CSS_SELECTOR, "div.comment-item")

# 第二层：内容特征验证
if len(content) < 2: continue  # 过短
if content in exclude_keywords: continue  # 关键词黑名单

# 第三层：智能模式识别
if re.match(r'^(创作中心|业务合作)$', content): continue
if '沪ICP备' in content: continue

# 第四层：语义验证
chinese_count = len(re.findall(r'[\u4e00-\u9fff]', content))
if chinese_count < 2: continue  # 至少2个汉字
```

#### 2. 更精准的选择器

```python
# 旧版本：过于宽泛
elements = driver.find_elements(By.TAG_NAME, "div")

# 新版本：精准定位评论区
comment_selectors = [
    "div.comment-item",           # 标准评论项
    "#noteComment .comment",      # 评论区内的评论
    "div[class*='CommentItem']",  # 模糊匹配评论组件
]
```

#### 3. 智能内容验证

```python
def is_valid_comment_text(text):
    # 长度检查
    if len(text) < 2: return False
    
    # 关键词黑名单
    for pattern in exclude_patterns:
        if re.search(pattern, text):
            return False
    
    # 必须包含实际文字
    chinese = len(re.findall(r'[\u4e00-\u9fff]', text))
    english = len(re.findall(r'[a-zA-Z]', text))
    
    return chinese >= 2 or english >= 4
```
