### JSON结构
```json
{
  "note_info": {
    "note_id": "string",
    "note_title": "string",
    "note_url": "string",
    "author": "string"
  },
  "comments": [
    {
      "username": "string",
      "content": "string",
      "likes": number,
      "timestamp": "string",
      "comment_type": "string"
    }
  ],
  "total_comments": number,
  "crawl_time": "string"
}
```

### CSV字段
```
序号,用户名,评论内容,点赞数,发布时间,评论类型

2,用户B,回复...,5,1小时前,回复
```

✅ 不同版本的数据可以混用

✅ 统一的数据分析流程
