# 小红书爬虫 - 防重复爬取使用指南

## 🎯 新增功能

改进版爬虫在原版基础上增加了以下防重复功能：

### 1. **自动记录已爬取笔记**
- 每次成功爬取后，自动保存笔记ID和爬取时间
- 历史记录保存在 `data/crawl_history.json`

### 2. **智能跳过已爬取内容**
- 批量处理时自动检测已爬取的笔记
- 显示跳过统计，节省时间和资源

### 3. **强制重新爬取选项**
- 需要更新数据时，可选择强制重爬
- 会更新历史记录的最后爬取时间

### 4. **详细统计信息**
- 查看累计爬取笔记数
- 查看累计评论数
- 查看最近爬取记录

## 📂 文件说明

### 新增文件
```
data/
├── crawl_history.json          # 爬取历史记录（新增）
└── comments/                   # 评论数据目录
    ├── comments_xxx_v6_nodup.json   # 完整数据（文件名新增_nodup标记）
    └── comments_xxx_v6_nodup.csv    # 简化数据
```

### 历史记录格式
```json
{
  "笔记ID": {
    "url": "笔记链接",
    "comment_count": 评论数量,
    "crawled_at": "首次爬取时间",
    "last_crawled": "最后爬取时间"
  }
}
```

## 🚀 使用方法

### 方法一：批量处理（推荐）

1. **创建URL列表文件** `note_urls.txt`
```
https://www.xiaohongshu.com/explore/xxxxx1
https://www.xiaohongshu.com/explore/xxxxx2
https://www.xiaohongshu.com/explore/xxxxx3
```

2. **运行脚本**
```bash
python comment_extractor_no_duplicate.py
```

3. **选择模式 2**（批量提取）

4. **查看自动跳过提示**
```
📊 批量处理统计
总笔记数: 10
已爬取: 5 个（将跳过）
待爬取: 5 个

已爬取的笔记:
  1. xxxxx1 (爬取于 2024-01-01 10:00:00)
  2. xxxxx2 (爬取于 2024-01-01 10:05:00)
  ...
```

### 方法二：强制重新爬取

当需要更新已爬取笔记的评论时：

1. 运行脚本
2. 在"高级选项"中选择 **y**（强制重新爬取）
3. 程序会重新爬取所有笔记并更新记录

```
🔧 高级选项:
是否启用调试模式？(y/n，默认n): n
是否强制重新爬取已处理的笔记？(y/n，默认n): y  ← 选择y
⚠️  警告: 强制模式将重新爬取所有笔记，包括已处理的！
```

### 方法三：查看历史统计

选择模式 4 可查看：
- 累计爬取笔记数
- 累计评论数
- 最近5条爬取记录


## 🔧 常见问题

### Q1: 如何完全重新开始爬取？
**A:** 删除 `data/crawl_history.json` 文件

### Q2: 历史记录会占用多少空间？
**A:** 每1000条记录约占50KB，非常小

### Q3: 如何只重新爬取部分笔记？
**A:** 
- 方法1: 在 `crawl_history.json` 中删除对应笔记记录
- 方法2: 创建新的URL列表文件

### Q4: 笔记有新评论了，怎么更新？
**A:** 使用强制重新爬取模式，或删除该笔记的历史记录

### Q5: 多台电脑如何共享爬取进度？
**A:** 复制 `data/crawl_history.json` 文件到其他电脑

## 📈 性能优化建议

1. **大批量爬取**（1000+笔记）
   - 分批次进行，每次200-300个
   - 利用历史记录自动跳过已爬取

2. **定期更新**
   - 每天/每周运行一次
   - 自动只爬取新笔记

3. **数据备份**
   - 定期备份 `data/` 目录
   - 特别是 `crawl_history.json`
