## 📁 输出文件说明

### 采集数据文件

运行 `comment_extractor_optimized.py` 后，在 `data/comments/` 目录生成：

```
data/comments/
├── comments_[笔记ID]_[时间].json    # 完整JSON数据
├── comments_[笔记ID]_[时间].csv     # 表格数据
└── summary_[时间].txt               # 统计报告
```

#### JSON 文件结构

```json
{
  "note_info": {
    "note_id": "66abc123",
    "note_title": "笔记标题",
    "note_url": "https://...",
    "author": "作者名"
  },
  "comment_count": 50,
  "comments": [
    {
      "comment_id": "comment_1",
      "username": "用户名",
      "content": "评论内容",
      "time": "2天前",
      "likes": 15
    }
  ]
}
```

#### CSV 文件字段

| 字段           | 说明       |
| -------------- | ---------- |
| comment_id     | 评论唯一ID |
| note_id        | 笔记ID     |
| note_title     | 笔记标题   |
| username       | 用户名     |
| content        | 评论内容   |
| time           | 发布时间   |
| likes          | 点赞数     |
| content_length | 内容长度   |
| collected_at   | 采集时间   |

## 🔧 常见问题

### Q1: 连接不上Chrome？

```
检查：
✓ 是否运行了 start_xiaohongshu_chrome.bat
✓ Chrome是否在调试模式（端口9222）
✓ 关闭其他Chrome实例

解决：
1. 关闭所有Chrome窗口
2. 重新运行 start_xiaohongshu_chrome.bat
3. 再运行提取器
```

### Q2: 提取的评论很少？

```
原因：
- 笔记本身评论少
- 需要更多滚动次数
- 页面未完全加载

解决：
1. 手动滚动到评论区底部
2. 增加 max_scrolls 参数（20 → 30）
3. 等待页面完全加载后再提取
```

### Q3: 还是有少量无效数据？

```
正常现象：
- 1-5%的误提取率是正常的
- 复杂页面结构难以100%准确

后续处理：
df = df[df['content_length'] > 10]  # 过滤短内容
df = df[df['username'] != '匿名用户']  # 过滤匿名
```

### Q4: 如何合并多个CSV文件？

```python
import pandas as pd
from pathlib import Path

# 读取所有CSV
csv_files = Path('data/comments').glob('comments_*.csv')
dfs = [pd.read_csv(f) for f in csv_files]

# 合并
merged = pd.concat(dfs, ignore_index=True)

# 去重
merged = merged.drop_duplicates(subset=['content'])

# 保存
merged.to_csv('data/all_comments.csv', index=False, encoding='utf-8-sig')
```
