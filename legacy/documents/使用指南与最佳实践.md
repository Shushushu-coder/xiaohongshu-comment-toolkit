#### ✅ 推荐做法

**小批量多次运行**

```
第1天: 爬取 20 个笔记（约1小时）
第2天: 爬取 20 个笔记
第3天: 爬取 20 个笔记
```

### 2. 情感分析（简单版）

```python
# 定义关键词
positive_keywords = ['好用', '推荐', '喜欢', '赞', '值得', '满意', 
                     '棒', '不错', '优秀', '喜爱', '心水']
negative_keywords = ['失望', '差', '不好', '坑', '退货', '后悔', 
                     '难用', '不推荐', '垃圾', '踩雷']

# 计算情感得分
df['positive_count'] = df['content'].apply(
    lambda x: sum(1 for kw in positive_keywords if kw in str(x))
)
df['negative_count'] = df['content'].apply(
    lambda x: sum(1 for kw in negative_keywords if kw in str(x))
)

# 判断情感
df['sentiment'] = df.apply(
    lambda row: 'positive' if row['positive_count'] > row['negative_count']
    else 'negative' if row['negative_count'] > row['positive_count']
    else 'neutral',
    axis=1
)

# 统计结果
print("\n情感分析结果:")
print(df['sentiment'].value_counts())
print(f"\n正面比例: {(df['sentiment']=='positive').sum() / len(df) * 100:.1f}%")
```

### 3. 关键词分析

```python
import jieba
from collections import Counter

# 分词
all_words = []
for text in df['content']:
    words = jieba.cut(str(text))
    # 过滤停用词和短词
    all_words.extend([w for w in words if len(w) > 1 and w not in ['的', '是', '了', '在']])

# 统计高频词
word_counts = Counter(all_words)
top_words = word_counts.most_common(30)

print("\n高频关键词 (Top 30):")
for word, count in top_words:
    print(f"{word}: {count} 次")
```

## 📝 论文写作建议

### Methods 部分

```markdown
#### Data Collection

We developed a web scraper to collect user comments about the target brand 
from Xiaohongshu (Little Red Book), a popular Chinese social commerce platform 
with over 300 million monthly active users. The scraper employed several 
anti-detection mechanisms to ensure ethical and sustainable data collection:

1. Human behavior simulation (random delays, mouse movements)
2. Respectful crawling rate (3-8 seconds between requests)
3. Cookie-based authentication (avoiding repeated logins)

#### Data Quality Control

To ensure data authenticity, we implemented a multi-dimensional user credibility 
scoring system based on five heuristics:

| Dimension | Weight | Description |
|-----------|--------|-------------|
| Account Age | 20% | Older accounts are more trustworthy |
| Content Diversity | 25% | Users posting across multiple categories |
| Engagement Ratio | 15% | Average engagement per post within normal range |
| Posting Pattern | 20% | Irregular posting times suggest human behavior |
| Follower Quality | 20% | Reasonable follower-to-engagement ratio |

Users with credibility scores below 0.6 (threshold determined through pilot study) 
were filtered out, resulting in N high-quality comments from M verified users.

#### Validation

We validated our filtering approach through:
1. Manual sampling (n=100, κ=0.XX agreement with human annotators)
2. Cross-validation with verified purchase reviews from e-commerce platforms
3. Comparison with ground truth data from recruited users
```

### Limitations 部分

```markdown
#### Data Collection Limitations

While our heuristic-based filtering method effectively removes obvious marketing 
accounts (as validated by manual sampling), it may not detect highly sophisticated 
fake accounts that mimic authentic user behavior patterns. To mitigate this risk:

1. We conducted manual validation on a random sample (n=100) and achieved 
   substantial agreement with human annotators (κ=0.XX)
   
2. We cross-validated our results with verified purchase reviews from major 
   e-commerce platforms, finding XX% consistency in sentiment distribution
```
